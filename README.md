# 🚗 Car Sales Form Project

Aplicação web focada no desenvolvimento de um formulário completo e semântico para anúncio e venda de veículos. O projeto foi construído para aplicar boas práticas de usabilidade, acessibilidade, validação de campos nativa e estilização moderna com HTML5 e CSS3.

Desenvolvido como atividade prática durante o curso **Formação Front-end** da escola **Hora de Codar** na Udemy.

---

## 🚀 Destaques do Projeto

- 📝 **HTML Semântico:** Utilização correta de tags como `<form>`, `<fieldset>`, `<legend>`, `<label>`, `<input>`, `<select>` e `<textarea>`.
- ✅ **Validação Nativa:** Uso de atributos como `required`, `type`, `placeholder` e restrições para garantir o preenchimento correto das informações do veículo.
- 🎨 **Estilização e UX:** Interface limpa, organizada e agradável ao usuário, com agrupamento lógico de seções (dados pessoais, dados do veículo e opcionais).
- 📐 **Layout Responsivo:** Adaptação perfeita do formulário para diferentes tamanhos de tela.

---

## 🛠️ Tecnologias Utilizadas

- **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Estruturação semântica e formulários acessíveis.
- **[CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS):** Estilização de inputs, botões, estados de foco e layout responsivo.
- **[Git & GitHub](https://github.com/):** Controle de versão do código.
